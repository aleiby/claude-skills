# UI Mockup Review Rubric

Score each dimension: PASS / FAIL

## Dimensions

1. **Layout fidelity** — Does the layout match the requested structure (sidebar, header, grid, etc.)?
2. **Visual hierarchy** — Is there a clear reading order? Primary actions stand out?
3. **Spacing/alignment** — Consistent padding, margins, alignment across elements?
4. **Typography** — Is text legible, properly sized, and consistently styled?
5. **Color coherence** — Palette is harmonious, accent colors used purposefully?
6. **Realism** — Does it look like a real app screenshot, not a rough sketch?
7. **Artifacts** — No distorted elements, broken borders, or impossible UI patterns?

## Decision

| Result | Condition |
|--------|-----------|
| **ACCEPT** | All critical dimensions PASS |
| **RETRY_FAST** | Layout is close but spacing/alignment off, or wrong color scheme |
| **RETRY_PRO** | Layout fundamentally wrong, or text is gibberish |
| **FAIL** | Not a UI at all — reclassify request |
